# 🦠 COVID-19 Data Analysis Dashboard | SQL & Tableau

## 📌 Overview
The COVID-19 Data Analysis Dashboard is a Business Intelligence project developed using **SQL** and **Tableau** to analyze global COVID-19 trends. The project involves extracting, cleaning, and analyzing COVID-19 data using SQL, followed by creating interactive Tableau dashboards to visualize cases, deaths, vaccinations, and country-wise comparisons. This project demonstrates end-to-end data analysis, from database querying to dashboard development.

## 🎯 Objective
The objective of this project is to analyze COVID-19 data and provide meaningful insights into the spread of the pandemic, vaccination progress, and mortality trends across different countries using SQL queries and interactive Tableau visualizations.

## 📊 Dashboard Highlights
- Total Confirmed Cases
- Total Deaths Analysis
- Total Vaccinations Trend
- Country-wise COVID-19 Comparison
- Daily Cases & Death Trends
- Interactive Filters and Dynamic Visualizations

## 🛠️ Tech Stack
- SQL Server
- Microsoft SQL Server Management Studio (SSMS)
- Tableau
- Microsoft Excel
- Data Cleaning & Data Analysis

## 📈 Key Insights
- Analyzed global COVID-19 cases, deaths, and vaccination data.
- Used SQL queries for data extraction, filtering, aggregation, and trend analysis.
- Built an interactive Tableau dashboard to visualize country-wise performance and time-based trends.
- Enabled data-driven insights through dynamic charts and dashboards.

## 💡 Skills Demonstrated
SQL • Joins • GROUP BY • Aggregate Functions • Data Cleaning • Data Analysis • Tableau • Dashboard Development • Data Visualization • Business Intelligence
